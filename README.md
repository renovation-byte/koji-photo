# 工事写真台帳（koji-photo）

**現場で撮影したら、その場で工事写真台帳が完成する** スマホ向けWebアプリ（PWA）。

- 公開先：https://renovation-byte.github.io/koji-photo/
- 仕様：`obsidian-notes` リポジトリの「工事写真台帳アプリ/確定仕様書｜工事写真台帳アプリ.md」

## いまできること（段階1・最小構成）

1. 案件登録（工事番号は自動採番）
2. アプリ内カメラで連続撮影（工種・施工箇所・施工状況を引き継ぎ、全写真に自動設定）
   - 撮った写真は画面下に✓付きで並び、要らない写真だけタップで台帳から外す
   - 工種などを切り替えると「さっき撮ったN枚もこの○○にしますか？」
   - 施工後を撮るとき、同じ施工箇所の施工前の写真を透かして同じ角度で撮れる
   - カメラが使えない端末は「標準カメラ」
3. アルバムから登録（写真の記録の撮影日時を使う・同じ写真は二重登録しない）
4. 写真一覧（工種・撮影日・施工箇所で絞り込み、拡大・編集、まとめて編集、ゴミ箱30日）
5. 写真台帳の自動生成（A4縦・1ページ3枚標準／2枚・4枚、表紙、ページ番号、並び替え4種）
6. PDF（標準／軽量版、共有・保存・印刷、ファイル名「工事名_工事写真台帳_作成日.pdf」）

写真は**この端末の中（IndexedDB）**に保存。クラウド（Supabase）との同期・ログインは段階2。

## 開発

```
npm install
npm run dev        # http://localhost:5173/koji-photo/
npm test           # ロジックのテスト（vitest）
npm run build      # dist/ に出力
```

`main` に入ると GitHub Actions がビルドして Pages に公開する（`.github/workflows/deploy.yml`）。
